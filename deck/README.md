# Eatroz — Investor Pitch Deck

This directory contains the presentation assets and interactive HTML pitch deck for Eatroz.

## Files

- **`index.html`**: The interactive HTML pitch deck featuring dark-mode tokens, 12 slides, Fraunces + Inter typography, and competitive quadrant analysis.
- **`source-docs/`**: Outlines and source references for the pitch deck (`pitch_deck_outline.md`, `Pitch_Deck_Outline.pdf`).
- **Reference imagery**: Competitor packaging reference images for visual comparison slides.
